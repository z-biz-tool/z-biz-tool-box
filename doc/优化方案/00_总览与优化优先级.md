## 0.2 项目独特价值（为什么值得单独优化）

z-biz-tool-box 与其它 z-biz-tool 子项目最大的不同在于它是一个**平台**而非单一功能应用：

1. **浮层式即时唤起**：`⌥Space` / `⌃⌘K` 全局快捷键唤起 Spotlight 风格浮层，用完即隐（[`../../src-tauri/src/lib.rs`](../../src-tauri/src/lib.rs) 第 39-63 行；关闭改为隐藏不退出，第 66-75 行）。对标 Raycast / Alfred / uTools 的“呼出即用”理念。
2. **双层工具体系**：
   - **内置工具**：源码即插件，`src/plugins/<group>/<Name>.tsx` 放文件即自动注册（[`../../src/plugins/_registry.tsx`](../../src/plugins/_registry.tsx) 用 `import.meta.glob(eager:true)` 收集），当前约 28 个工具（编码 6 / 文本 8 / 加密 4 / 转换 6 / 网络 2 / 系统 2）。
   - **外部插件**：`~/.z-biz-tools/plugins/<id>/` 下 `plugin.json + main.html`，通过 iframe 沙箱加载，宿主注入 `window.zBiz` 受限 API（[`../../src/plugins/external/PluginIframe.tsx`](../../src/plugins/external/PluginIframe.tsx)、[`../../src/plugins/external/api.ts`](../../src/plugins/external/api.ts)）。
3. **去中心化插件市场**：用户自配 base URL 市场源，`GET {base}/list` 拉列表、按 id 拼下载地址（[`../../src/plugins/external/market.ts`](../../src/plugins/external/market.ts)、[`../../docs/market-spec.md`](../../docs/market-spec.md)），无需中心服务器。
4. **AI 可生产的插件规范**：`_SKILL/插件开发/` 是给 AI 阅读的插件开发说明书（[`../../_SKILL/插件开发/SKILL.md`](../../_SKILL/插件开发/SKILL.md)），降低造工具门槛。

> 平台属性决定了它的核心风险面是**“执行第三方代码”**：安全与隔离是第一优先级，其次才是功能与性能。

## 0.3 立即处理项（P0，安全底线）

以下 4 项为**已确认缺陷**（证据见 [01](./01_现状审计与问题清单.md)），触及“执行第三方代码”的安全底线，建议最先处理：

- **P0-1 关闭 TLS 证书校验**：HTTP 后端命令硬编码 `.danger_accept_invalid_certs(true)`（[`../../src-tauri/src/plugin_engine.rs`](../../src-tauri/src/plugin_engine.rs) 第 36 行）。该命令既被内置 HTTP 工具用，也通过 `zBiz.invoke` 白名单暴露给**所有外部插件**，等于任何插件都能发起免证书校验的请求，可被中间人利用。
- **P0-2 远程插件无完整性校验**：安装流程仅下载 `plugin.json + main.html` 写盘即加载，无签名 / 无哈希 / 无来源可信度校验（[`../../src/plugins/external/installer.ts`](../../src/plugins/external/installer.ts)），且允许 `http://` 明文源（[`../../src/plugins/external/market.ts`](../../src/plugins/external/market.ts) 第 51 行）。供应链风险。
- **P0-3 iframe 沙箱过宽 + 无 CSP**：iframe `sandbox="allow-scripts allow-forms allow-same-origin allow-popups"`（[`../../src/plugins/external/PluginIframe.tsx`](../../src/plugins/external/PluginIframe.tsx) 第 162 行），`allow-scripts` 与 `allow-same-origin` 同时开启会显著削弱沙箱；应用级 `tauri.conf.json` 的 `"csp": null`（[`../../src-tauri/tauri.conf.json`](../../src-tauri/tauri.conf.json) 第 37 行）。
- **P0-4 插件无权限模型**：所有外部插件无条件获得完整 `zBiz` API，含 `readClipboard`、任意 URL 的 `http_request`、`hide/showMainWindow`（[`../../src/plugins/external/api.ts`](../../src/plugins/external/api.ts)）。缺少 manifest 声明式权限 + 用户授权 + 危险操作确认。

## 0.5 核心原则（贯穿全部文档）

1. **插件沙箱隔离**：第三方插件运行在最小权限沙箱内，不能触达宿主 DOM / localStorage / Tauri 命令，除非通过受控桥接。
2. **来源可校验**：远程插件必须可验证完整性与来源（哈希 / 签名 / HTTPS），拒绝静默信任。
3. **危险操作需确认**：卸载、覆盖、递归删除、对外发起请求等破坏性/敏感动作需显式用户确认。
4. **Agent 不自动执行破坏操作**：任何 AI/Agent 辅助只产出建议或需人确认的动作，绝不自动执行删除、覆盖、外发数据等破坏性操作。
