# 02 · 产品能力与交互优化

> 状态：设计方案，未实现；基线 `84aa094`；当前事实 = 静态代码证据，指标 = 拟定验收目标。

本文覆盖工具箱的**完整使用流程**，逐环节列出“当前实现（证据）→ 缺口 → 优化建议 → 优先级”。对标 Raycast / Alfred / uTools 的交互理念，但不复制其商业实现，也不编造竞品实时数据。

## 2.0 当前交互主链路（读源码得出）

`⌥Space` 唤起 → [`../../src/App.tsx`](../../src/App.tsx) 默认视图 `spotlight`（第 32 行）→ [`../../src/_shared/Spotlight.tsx`](../../src/_shared/Spotlight.tsx) 三列浮层（导航 / 分类 / 结果）→ 选中 `setActiveKey` → `parseActiveKey`（[`../../src/App.tsx`](../../src/App.tsx) 第 13-29 行）分流到 `builtin`（渲染工具组件）或 `external`（`PluginIframe`）→ `esc` 逐级返回、spotlight 下 `esc` 隐藏窗口（第 46-77 行）。

## 2.1 工具发现与分类

**现状**：Spotlight 提供 `all / builtin / external / starred / recent` 五个导航（[`../../src/_shared/Spotlight.tsx`](../../src/_shared/Spotlight.tsx) 第 38、71-133 行）；内置工具按 6 个 group（编码/文本/加密/转换/网络/系统）分类，group 由文件路径自动派生（[`../../src/plugins/_registry.tsx`](../../src/plugins/_registry.tsx) 第 107-111、143-151 行）。

**缺口**：
- 外部插件的分类固定为“📦 插件名”（[`../../src/_shared/Spotlight.tsx`](../../src/_shared/Spotlight.tsx) 第 88 行），无法按功能归类到编码/文本等，插件多了以后混在一起。
- 无“常用/推荐”智能排序，`recent` 只保留 8 条（[`../../src/stores/uiStore.ts`](../../src/stores/uiStore.ts) 第 83-86 行）。
- 无标签/别名体系，只能靠 `keywords`/`cmds` 字符串匹配。

**建议（P1）**：
- manifest 增加 `category` 字段，允许外部插件归入内置 group；Spotlight 分类合并展示。
- `recent` 升级为“频率 + 时近”加权排序（frecency），并把上限做成可配置。
- 支持用户自定义别名（alias）与标签，落到 `uiStore`。

## 2.2 启动与运行

**现状**：内置工具选中即 `activeTool.render()` 同步渲染（[`../../src/App.tsx`](../../src/App.tsx) 第 242-243 行）；外部工具渲染 `PluginIframe`（第 244-245 行），iframe 顶部有“重新加载 / 打开目录”条（[`../../src/plugins/external/PluginIframe.tsx`](../../src/plugins/external/PluginIframe.tsx) 第 138-150 行）。

**缺口**：
- 外部插件加载无 loading 态与超时提示，iframe 白屏时用户无反馈（仅在 `plugin.error` 时显示 Alert，第 93-112 行）。
- 无“运行中插件崩溃”兜底（iframe 内 JS 报错宿主不可见）。
- 内置工具全量 eager 加载拖慢首屏（见 [01](./01_现状审计与问题清单.md) D9）。

**建议（P1）**：iframe 增加加载骨架屏 + N 秒超时提示 + 捕获 `error` 事件；内置工具改懒加载（见 [03](./03_技术架构与性能优化.md)）。

## 2.3 插件安装 / 更新 / 卸载

**现状**：
- 安装：MarketView / PluginMarket 调 `installRemotePlugin`（[`../../src/plugins/external/installer.ts`](../../src/plugins/external/installer.ts) 第 87-140 行），成功后 `refresh` 重扫。
- 更新：远程列表对比本地版本，`isNewer` 为真时展示“v旧 → v新”更新项（[`../../src/plugins/system/PluginMarket.tsx`](../../src/plugins/system/PluginMarket.tsx) 第 121-166 行）。
- 卸载：MarketView `Popconfirm` 确认 → `uninstallLocalPlugin` → Rust `uninstall_plugin`（[`../../src/_shared/MarketView.tsx`](../../src/_shared/MarketView.tsx) 第 233-277 行、[`../../src-tauri/src/lib.rs`](../../src-tauri/src/lib.rs) 第 131-153 行）。

**缺口**：
- 安装/更新**无完整性与来源校验、无权限预览、无进度与失败回滚**（详见 [04](./04_数据安全与可靠性.md)）。安装是“下载即写盘即信任”。
- 更新是覆盖式写入（[`../../src/plugins/external/installer.ts`](../../src/plugins/external/installer.ts) 第 108-128 行 `mkdir` + `writeTextFile`），无版本备份，更新失败可能留下半成品目录。
- 无“批量更新”“更新日志展示”“安装来源标注”。

**建议（P0/P1）**：安装前展示权限清单 + 来源 + 哈希校验并需用户确认；更新采用“下载到临时目录 → 校验 → 原子替换 → 失败回滚”；卸载确认已具备，保持。

## 2.4 工具间数据传递

**现状**：**几乎没有**。工具之间唯一隐式通道是系统剪贴板（`useCopyToClipboard`，[`../../src/_shared/hooks.ts`](../../src/_shared/hooks.ts) 第 12-35 行）与每工具独立的持久化输入（`usePluginInput`，第 57-73 行）。没有“把 A 工具输出送到 B 工具输入”的管道。

**缺口**：这是工具箱类产品的核心体验短板。用户需手动复制→切换→粘贴。

**建议（P1）**：引入“结果动作条”——每个工具输出支持 `复制到剪贴板 / 发送到…（选择目标工具）/ 收藏片段`。实现上在 `uiStore` 增加一个轻量 `pipe`（暂存 payload + 目标 key），目标工具挂载时读取。跨内置工具直接传；传给外部插件需经 zBiz 桥接并受权限约束（见 [03](./03_技术架构与性能优化.md)、[04](./04_数据安全与可靠性.md)）。

## 2.5 收藏与最近

**现状**：`starred` / `recent` 持久化在 `uiStore`（[`../../src/stores/uiStore.ts`](../../src/stores/uiStore.ts) 第 66-86、149-157 行），Spotlight 有对应导航（[`../../src/_shared/Spotlight.tsx`](../../src/_shared/Spotlight.tsx) 第 99-103 行）。

**缺口**：
- `recent`/`starred` 存的是 tool `key`，对外部插件 key 形如 `ext::<id>::<code>`；插件卸载后这些 key 变悬空，`starred.map(...).filter(Boolean)`（第 100 行）会静默丢弃，用户收藏“凭空消失”且无提示。
- 收藏无排序/分组，无“置顶常用”。

**建议（P2）**：悬空 key 显式提示“插件已移除”；收藏支持手动排序与置顶。

## 2.6 搜索

**现状**：Spotlight 模糊匹配 `label + description + keywords + cmds + key`，空格分词 AND（[`../../src/_shared/Spotlight.tsx`](../../src/_shared/Spotlight.tsx) 第 135-140 行）；registry 侧也有 `searchTools`（[`../../src/plugins/_registry.tsx`](../../src/plugins/_registry.tsx) 第 176-184 行）。

**缺口**：
- 纯子串匹配，无拼音/首字母（如“jsh”→JSON 美化）、无模糊容错、无按使用频率排序。
- 无搜索历史 / 热门搜索。
- 内置与外部搜索逻辑分散在两处（Spotlight 与 registry），规则可能漂移。

**建议（P1）**：统一搜索打分（前缀 > 首字母/拼音 > 子串 > 频率加权），抽出单一 `searchTools` 供 Spotlight/QuickOpen/tray 复用。

## 2.7 全局快捷键与 tray

**现状**：`⌥Space` 主快捷键 + `⌃⌘K` 兜底（[`../../src-tauri/src/lib.rs`](../../src-tauri/src/lib.rs) 第 39-63 行）；WebView 获焦时前端再兜底 hide 一次（[`../../src/App.tsx`](../../src/App.tsx) 第 63-73 行）。tray 左键展开菜单（[`../../src-tauri/src/tray.rs`](../../src-tauri/src/tray.rs) 第 110 行）。

**缺口（对应 [01](./01_现状审计与问题清单.md) D6/D7）**：
- tray 工具子菜单因前端从不 `register_tools` 而永久“加载中…”。
- tray 点击工具 `emit("select-tool")` 无前端监听，点了不跳转。
- 快捷键不可自定义，与 Alfred/Raycast 冲突时只能改系统设置（[`../../src-tauri/src/lib.rs`](../../src-tauri/src/lib.rs) 第 37-38 行注释亦承认）。

**建议（P1）**：App 挂载后调用 `register_tools` 推送启用工具分组；前端 `listen("select-tool")` → `setActiveKey`；快捷键做成可配置（`uiStore` + Preferences）。

## 2.8 Agent 辅助

**现状**：**当前无真实 Agent 能力**。`../../src/agent/` 是未被引用的 SQL Agent 占位死代码（[`../../src/agent/AgentManager.ts`](../../src/agent/AgentManager.ts) 第 36-183 行全为 TODO + 伪造响应，见 [01](./01_现状审计与问题清单.md) D8）。

**建议（P2，受核心原则约束）**：若要做工具箱 Agent 辅助，只能做**非破坏性**能力：
- 自然语言 → 推荐工具 / 生成参数（如“把这段 base64 解码再 JSON 格式化”→ 串联工具链，产出**建议**，用户点确认才执行）。
- 文本智能处理建议（总结/翻译/正则生成），结果填回输入框由用户复核。
- **红线**：Agent 不得自动调用 `uninstall_plugin`、不得自动覆盖文件、不得自动对外发送用户数据；任何写/删/外发操作必须经用户显式确认（见 [04](./04_数据安全与可靠性.md) 4.5）。
- 先决条件：清理或明确隔离 `../../src/agent/` 死代码，避免误导后续开发。

## 2.9 交互优化优先级汇总

| 环节 | 缺口 | 优先级 |
| --- | --- | --- |
| 安装/更新 | 无校验/无权限预览/无回滚 | P0（安全）+ P1（体验） |
| tray 闭环 | D6/D7 菜单与导航未通 | P1 |
| 工具间数据传递 | 无管道 | P1 |
| 搜索 | 无拼音/频率排序/逻辑分散 | P1 |
| 启动运行 | 外部插件无 loading/超时/崩溃兜底 | P1 |
| 发现分类 | 外部插件无法按功能归类 | P1 |
| 快捷键 | 不可配置 | P2 |
| 收藏/最近 | 悬空 key 无提示、无排序 | P2 |
| Agent 辅助 | 无真实能力（死代码） | P2（非破坏性） |
