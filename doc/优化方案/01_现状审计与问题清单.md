> 状态：设计方案，未实现；基线 `84aa094`；当前事实 = 静态代码证据，指标 = 拟定验收目标。

本文基于对仓库源码的静态阅读，逐模块列出**证据**与**判定**。判定分三类：

- ✅ **已确认缺陷**：源码可直接读出、逻辑上必然成立的问题。

行号均来自实际读取结果；证据路径相对本目录两层（`../../src/...`、`../../src-tauri/...`）。

## 2. 已确认缺陷（✅）

### D1 · HTTP 后端强制关闭 TLS 证书校验 【P0 · 安全】
证据：[`../../src-tauri/src/plugin_engine.rs`](../../src-tauri/src/plugin_engine.rs) 第 34-37 行
```
reqwest::blocking::Client::builder()
    .timeout(std::time::Duration::from_secs(30))
    .danger_accept_invalid_certs(true)
```
影响：`http_request` 命令被内置 HTTP 工具（[`../../src/plugins/network/HttpTester.tsx`](../../src/plugins/network/HttpTester.tsx) 第 74 行）调用，也通过 `zBiz.invoke` 白名单暴露给**全部外部插件**（[`../../src/plugins/external/api.ts`](../../src/plugins/external/api.ts) 第 70-76 行）。所有 HTTPS 请求都不验证证书，可被中间人窃取 / 篡改。这是全局无条件行为，用户无法关闭。

### D2 · 远程插件安装无任何完整性/来源校验 【P0 · 供应链】
证据：[`../../src/plugins/external/installer.ts`](../../src/plugins/external/installer.ts) 第 87-140 行。流程为 `downloadText(plugin.json) → 写盘 → downloadText(main.html) → 写盘`，仅做 `validateManifestAgainstEntry`（第 58-75 行，校验 id/name/features 是否存在），**无哈希、无签名、无可信源白名单**。`main.html` 是可执行 HTML/JS，写盘后即被 iframe 加载运行。

### D3 · 市场源允许 http:// 明文下载 【P0 · 供应链】
证据：[`../../src/plugins/external/market.ts`](../../src/plugins/external/market.ts) 第 42-55 行 `validateMarketUrl` 显式接受 `http:`（注释“内网联调友好”）。结合 D2，插件包可经明文 HTTP 下发并被篡改，无 TLS 保护。

### D4 · iframe 沙箱过宽 + 应用无 CSP 【P0 · 隔离】
证据：[`../../src/plugins/external/PluginIframe.tsx`](../../src/plugins/external/PluginIframe.tsx) 第 162 行 `sandbox="allow-scripts allow-forms allow-same-origin allow-popups"`；[`../../src-tauri/tauri.conf.json`](../../src-tauri/tauri.conf.json) 第 36-37 行 `"security": { "csp": null }`。`allow-scripts` + `allow-same-origin` 同时开启，使 iframe 内容保留其源并可运行脚本，沙箱隔离强度大幅下降；无 CSP 意味着插件页可自由内联脚本 / 连接任意源。

### D5 · 外部插件无权限模型，全量授予 zBiz API 【P0 · 权限】
证据：[`../../src/plugins/external/api.ts`](../../src/plugins/external/api.ts) 第 40-101 行 `buildZbizApi(pluginId)` 对任何插件都返回同一份完整能力：`copyToClipboard`、`readClipboard`、`notify`、`invoke('http_request')`、`storage`、`hide/showMainWindow`、`log`。manifest（[`../../src/plugins/external/types.ts`](../../src/plugins/external/types.ts) 第 30-47 行 `ExternalPluginManifest`）**无 permissions 字段**，用户无从授权，插件默认可静默读剪贴板、对外发请求。

### D6 · tray 工具菜单永久停留“加载中…” 【P1 · 功能未闭环】
证据：Rust 端 `register_tools` 命令存在（[`../../src-tauri/src/lib.rs`](../../src-tauri/src/lib.rs) 第 84-87 行），tray 初始以空 groups 构建、渲染“加载中…”占位（[`../../src-tauri/src/tray.rs`](../../src-tauri/src/tray.rs) 第 86-96 行）。但对 `../../src` 全量检索 `register_tools|registerTools`（含 `.ts/.tsx`）**0 命中**——前端从未调用该命令。结论：菜单栏下拉的工具子菜单永远是空的“加载中…”。

### D7 · tray 点击工具无法导航（select-tool 无监听） 【P1 · 功能未闭环】
证据：[`../../src-tauri/src/tray.rs`](../../src-tauri/src/tray.rs) 第 127-132 行，点击工具项时 `app.emit("select-tool", tool_key)` 并唤起窗口。但对 `../../src` 检索 `select-tool` **0 命中**——前端无 `listen("select-tool")`。即便 D6 修复，点击 tray 工具也只会弹出窗口、停在 spotlight，不会打开对应工具。

### D8 · agent/ 目录为占位死代码 【P2 · 误导】
证据：[`../../src/agent/AgentManager.ts`](../../src/agent/AgentManager.ts) 全部方法体是 `// TODO: 调用 Agent 服务` 加伪造响应（第 36-183 行，`query/optimize/analyze/diagnoseError` 均返回硬编码 SQL/文案）。检索显示 `useAgentStore` 仅被 [`../../src/agent/AgentPanel.tsx`](../../src/agent/AgentPanel.tsx) 内部引用，`App.tsx` 与任何工具都未 import。这是一套“SQL Agent”（[`../../src/agent/types.ts`](../../src/agent/types.ts) 面向数据库连接），与工具箱无关，疑似从 db 子项目拷贝的残留。当前**工具箱不存在任何真实 Agent 辅助能力**。

### D9 · 内置工具全部 eager 打包，无懒加载/分包 【P1 · 性能】
证据：[`../../src/plugins/_registry.tsx`](../../src/plugins/_registry.tsx) 第 51-54 行 `import.meta.glob([...], { eager: true })`，且 `render()`（第 129-132 行）直接返回已加载组件。约 28 个工具（含 37.6KB 的 [`../../src/plugins/text/JsonTool.tsx`](../../src/plugins/text/JsonTool.tsx)、9KB 的 HashTool 等）全部进入首屏 bundle，无 `React.lazy`/动态 import。浮层追求“秒开”，全量加载与该目标冲突。

### D10 · 外部插件每次启动全量重扫，无缓存/持久化 【P2 · 性能】
证据：[`../../src/plugins/external/store.ts`](../../src/plugins/external/store.ts) 第 12-31 行注释明确“不持久化(每次启动重新扫)”，`refresh` 每次遍历目录、逐个 `readTextFile` + `JSON.parse` + `convertFileSrc`（[`../../src/plugins/external/scanner.ts`](../../src/plugins/external/scanner.ts) 第 24-88 行）。插件多时启动扫描为串行 IO。

### D11 · 内置工具网络请求实现不统一 【P2 · 一致性/可靠性】
证据：[`../../src/plugins/convert/ExchangeRate.tsx`](../../src/plugins/convert/ExchangeRate.tsx) 第 73 行直接用浏览器 `fetch("https://open.er-api.com/...")`，而 `_SKILL` 文档（[`../../_SKILL/插件开发/SKILL.md`](../../_SKILL/插件开发/SKILL.md) 第 141 行）明确要求“不要直接 fetch，用 tauri-plugin-http”。HttpTester 走 `invoke('http_request')`。两套网络路径行为/超时/CORS 表现不一致。

### D12 · 无任何测试 【P1 · 可靠性】
证据：[`../../package.json`](../../package.json) 第 6-13 行 scripts 只有 `dev/build/preview/tauri/typecheck/format`，无 `test`；无 vitest/jest 依赖。Glob `**/*.{test,spec}.*` 在项目源码内 0 命中（仅 `node_modules` 内有第三方自带测试）。平台执行第三方代码却无回归测试，风险高。

### D13 · 剪贴板复制降级路径依赖已废弃 API 【P2 · 兼容】
证据：[`../../src/_shared/hooks.ts`](../../src/_shared/hooks.ts) 第 18-32 行降级使用 `document.execCommand("copy")`（已废弃）。同时外部插件走的是 `@tauri-apps/plugin-clipboard-manager`（[`../../src/plugins/external/api.ts`](../../src/plugins/external/api.ts) 第 47 行），内置工具走 `navigator.clipboard`——两条剪贴板路径并存。

### D14 · postMessage 广播使用通配 targetOrigin 【P2 · 加固项】
证据：[`../../src/plugins/external/PluginIframe.tsx`](../../src/plugins/external/PluginIframe.tsx) 第 32-37 行 `iframe.contentWindow?.postMessage(msg, "*")`。虽然 `onMessage` 有 `ev.source !== iframe.contentWindow` 来源校验（第 43 行，🟢 好实践），但发送端用 `"*"`，若 iframe 被重定向到其它源，宿主响应（可能含 storage 数据）会被投递到非预期源。

### D15 · MarketView 单文件超大，可维护性差 【P2 · 工程】
证据：[`../../src/_shared/MarketView.tsx`](../../src/_shared/MarketView.tsx) 约 61.8KB 单文件，聚合了内置/已装/远程三类列表、安装、图标降级、分组渲染等。与 [`../../src/plugins/system/PluginMarket.tsx`](../../src/plugins/system/PluginMarket.tsx) 存在功能重叠（两处都做远程安装/版本对比），职责边界模糊。

## 3. 待验证假设（❓）

- **H1（已核实为 🟢）卸载有二次确认**：`uninstall_plugin` 走 Rust `remove_dir_all` 递归删除（[`../../src-tauri/src/lib.rs`](../../src-tauri/src/lib.rs) 第 131-153 行）。MarketView 的卸载入口用 antd `Popconfirm` 包裹（[`../../src/_shared/MarketView.tsx`](../../src/_shared/MarketView.tsx) 第 233-277 行），确认后才调 `uninstallLocalPlugin`（第 242 行）。**判定：主入口已有确认**，属应保留能力；剩余风险是所有卸载入口是否一致加了确认，需统一核对（见 [04](./04_数据安全与可靠性.md)）。
- **H2 `allow-same-origin` 下插件能否越权访问宿主**：iframe 源为 `asset://localhost`（[`../../src/plugins/external/scanner.ts`](../../src/plugins/external/scanner.ts) 第 65-67 行 `convertFileSrc`），与宿主 `tauri://` 跨源，理论上不能读宿主 localStorage；但 `allow-same-origin` 是否让同源 `asset://` 的其它插件页互相访问，需实测。
- **H3 ExchangeRate 浏览器 fetch 在打包 webview 是否被 CORS 拦截**：若被拦截则永远走离线兜底汇率（[`../../src/plugins/convert/ExchangeRate.tsx`](../../src/plugins/convert/ExchangeRate.tsx) 第 84-88 行），在线汇率形同虚设，需实机验证。
- **H4 http capability 放行 `http://**:*` 的实际暴露面**：[`../../src-tauri/capabilities/default.json`](../../src-tauri/capabilities/default.json) 第 35-45 行放行全部 http/https，结合 D1/D5，插件可借 `zBiz.invoke` 打到任意内网地址（SSRF 面），需结合权限模型评估。
- **H5 assetProtocol scope 是否足够收敛**：[`../../src-tauri/tauri.conf.json`](../../src-tauri/tauri.conf.json) 第 38-41 行 scope 为 `$HOME/.z-biz-tools/**`，看似收敛；但 fs capability（[`../../src-tauri/capabilities/default.json`](../../src-tauri/capabilities/default.json) 第 27-33 行）也限定同目录，需确认无其它越权读写路径。

## 4. 已存在能力（🟢，优化中应保留）

- **G1 卸载路径穿越防护**：Rust `uninstall_plugin` 对 id 严格白名单 `[a-zA-Z0-9._-]`（[`../../src-tauri/src/lib.rs`](../../src-tauri/src/lib.rs) 第 133-139 行），前端 `uninstallLocalPlugin` 也做同样正则校验（[`../../src/plugins/external/scanner.ts`](../../src/plugins/external/scanner.ts) 第 104 行）。防目录穿越，设计良好。
- **G2 单插件错误隔离**：`loadOnePlugin` 对每个插件 try/catch，失败记入 `error` 字段而非抛出（[`../../src/plugins/external/scanner.ts`](../../src/plugins/external/scanner.ts) 第 45-88 行），一个坏插件不拖垮整体扫描。
- **G3 postMessage 来源校验**：桥接 `onMessage` 校验 `ev.source`（[`../../src/plugins/external/PluginIframe.tsx`](../../src/plugins/external/PluginIframe.tsx) 第 43 行），阻止其它窗口伪造消息。
- **G4 invoke 白名单雏形**：`zBiz.invoke` 只放行 `http_request`，其它命令抛错（[`../../src/plugins/external/api.ts`](../../src/plugins/external/api.ts) 第 70-76 行）。方向正确，只是白名单里那一个命令本身 too powerful（见 D1）。
- **G5 市场列表 schema 严格校验**：`validateList` 校验 `schemaVersion===1`、id 唯一、id 字符合法、icon 仅 http(s)（[`../../src/plugins/external/market.ts`](../../src/plugins/external/market.ts) 第 168-256 行）。防脏数据。
- **G6 fs / asset scope 限定到 `~/.z-biz-tools`**：capability 与 assetProtocol 均把可读写/可加载范围收敛到应用自有目录（[`../../src-tauri/capabilities/default.json`](../../src-tauri/capabilities/default.json) 第 27-33 行、[`../../src-tauri/tauri.conf.json`](../../src-tauri/tauri.conf.json) 第 38-41 行）。
- **G7 输入持久化 hook**：`usePluginInput` 让工具输入跨会话保留（[`../../src/_shared/hooks.ts`](../../src/_shared/hooks.ts) 第 57-73 行），体验良好。
- **G8 关闭即隐藏不退出**：窗口 `CloseRequested` 被拦截改隐藏，常驻菜单栏（[`../../src-tauri/src/lib.rs`](../../src-tauri/src/lib.rs) 第 66-75 行），符合浮层产品预期。
