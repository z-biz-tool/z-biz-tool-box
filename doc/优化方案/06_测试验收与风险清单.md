## 6.1 测试基础设施建议

| 层级 | 框架 | 环境 | 说明 |
| --- | --- | --- | --- |
| 单元 | vitest + jsdom | 隔离 Node，mock Tauri API | 纯逻辑：market 校验、版本比较、scanner 解析、api 权限裁剪 |
| 集成 | vitest + testing-library/react | jsdom + mock iframe/postMessage | PluginIframe 桥接 RPC、Spotlight 搜索排序、uiStore persist |
| E2E | Playwright / WebDriverIO (Tauri driver) | 真实 Tauri 窗口 | 安装 → 加载 → 调用 API → 卸载 全流程 |
| 故障注入 | vitest（mock 异常）+ 手动 E2E | 隔离环境 | 网络超时、恶意插件、损坏 manifest |
| 安全 | 手动渗透 + 自动 lint 规则 | 隔离环境 | CSP bypass、sandbox escape、权限绕过 |
| 性能 | Lighthouse / 自定义计时 | 真实打包产物 | 首屏、工具打开、扫描延迟 |

**夹具原则**：所有测试用 `~/.z-biz-tools-test/`（隔离目录），不触碰用户真实插件/数据。mock Tauri `invoke`/`readDir`/`writeTextFile` 等 API，单元测试不依赖 Rust 二进制。

## 6.5 风险登记

| 风险 | 概率 | 影响 | 缓解措施 |
| --- | --- | --- | --- |
| 去 `allow-same-origin` 后现有插件不兼容 | 中 | 高 | T1.4 提前验证；若确有依赖，提供迁移指南 + 过渡期双模式 |
| CSP 过严导致内置工具网络请求被阻 | 中 | 中 | 逐步收紧：先 report-only → 观察 → enforce |
| hash 校验依赖市场源提供 sha256 字段 | 高 | 中 | 灰度期降级为"警告但不阻断"；推动源升级 |
| lazy 加载 chunk 丢失（离线/磁盘损坏） | 低 | 中 | ErrorBoundary + 重试 + fallback 提示 |
| http capability 收敛后 ExchangeRate 等工具不可用 | 中 | 低 | 白名单加入已知域名；或统一走 Rust http_request |
| uiStore persist migrate 写错导致数据丢失 | 低 | 高 | migrate 前备份 localStorage；单元测试覆盖迁移路径 |
| tray register_tools 序列化大列表导致 IPC 慢 | 低 | 低 | 只传 key+label，不传完整 meta |
| 插件签名（Ed25519）密钥管理复杂度 | 中 | 中 | 阶段 5 才引入；先用 hash 校验过渡 |
| Agent 辅助引入后绕过权限模型 | 低 | 高 | Agent caller 标记 + 破坏性操作拦截 + 不接入 invoke |
| E2E 测试环境不稳定（Tauri driver 兼容） | 中 | 中 | 优先保证单元+集成覆盖；E2E 作补充 |
