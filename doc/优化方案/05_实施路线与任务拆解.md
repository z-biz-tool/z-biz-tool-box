# 05 · 实施路线与任务拆解

> 状态：设计方案，未实现；基线 `84aa094`；当前事实 = 静态代码证据，指标 = 拟定验收目标。

本文给出 **5 个阶段** 的落地路线，每阶段含文件级改造点、任务编号、前置依赖、角色与资源假设、兼容/回滚策略。**本文档不执行任何改造**，仅提供规划。
